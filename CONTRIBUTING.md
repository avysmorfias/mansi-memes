# Contributing
Thank you for your interest in Mansi Memes!

This project is a small collection, and contributions do not have to be large. A correction, a useful source, a new Mansi expression, or a good meme idea can all be valuable.
## What you can contribute
You can contribute by:
* correcting a Mansi expression or translation;
* reporting a broken link or incorrect source;
* suggesting a Mansi word, expression, or idiom;
* sharing a dictionary, book, lesson, recording, or other useful source;
* suggesting a meme idea or template;
* contributing your own Mansi meme;
* improving the repository structure or data.

If you are not sure how to add something yourself, you can simply open an Issue and describe it.

## Adding a Mansi expression
When suggesting a new expression, please provide as much information as you know:
* the original Mansi expression;
* its meaning or translation;
* the Mansi variety, if known;
* the source where you found it, if known.

A source can be a dictionary, book, lesson, recording, website, or another reliable resource.

You do not need to know how to edit the JSON files. If you have useful material but are not sure how to add it to the repository, open an Issue and I can take care of the formatting.
## Corrections
If you notice a mistake in a Mansi expression, translation, source, variety, image path, or other part of the repository, please report it.

You can use the appropriate Issue template or open a Pull Request if you want to fix it yourself.

If you are unsure whether something is actually incorrect, feel free to report it anyway and explain why you think it may be a problem.
## Sources
Please provide a source whenever possible.

If you are contributing material from a dictionary, book, lesson, recording, or other resource, please give enough information to identify it.

If you are a speaker or otherwise have direct knowledge of the expression and there is no published source, you can explain that instead.

The purpose is not to make every contribution academic, but to make the origin of the Mansi material as clear as possible.
## Images and copyright
Please only contribute images that you created yourself or that you have permission to redistribute.

Do not assume that an image is free to use simply because it can be found on the Internet.

Third-party images used in the project are not covered by the project's CC BY-NC-SA 4.0 license. See [`LICENSE`](./LICENSE) for more information.

If you create an original meme using your own image, photograph, or screenshot, please mention that when submitting it.
## Pull requests
If you want to make changes directly:
1. Fork the repository.
2. Make your changes.
3. Check that file paths and links are correct.
4. If you changed `data/memes.json` or another JSON file, make sure the JSON remains valid.
5. Open a Pull Request and briefly explain what you changed.
6. If you added linguistic material, mention its source or explain where you got it.

Small Pull Requests are completely fine. You do not need to make a large contribution.
## Issues
Issues are welcome for:
* corrections;
* broken links;
* new resources;
* new Mansi expressions;
* meme ideas;
* questions and suggestions.

The repository includes Issue templates for some of these cases.
## Code of Conduct
Please follow the project's [Code of Conduct](./CODE_OF_CONDUCT.md) when participating in discussions or contributions.

Thank you for helping make the Mansi language a little more visible on the Internet.
